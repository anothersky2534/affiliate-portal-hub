# Affiliate Portal Hub 🚀
複数アフィリエイトポータル・特化サイトの稼働状態、最終更新日時、新規追加作品数を一括で監視・管理する統合ダッシュボードです。

## 🌟 主な機能
- **リアルタイム稼働監視**: 各サイトの最新更新日時、エラー検知、総登録記事数を集約表示
- **新着作品プレビュー**: 毎朝の自動更新で追加された作品タイトルを即座に確認
- **ASPクイックアクセス**: DUGA、FANZA、Search Console、Analyticsへのショートカット
- **サイトの動的追加・編集**: ブラウザ上から新しいサイトを自由に追加・管理
- **設定エクスポート/インポート**: 設定JSONをバックアップ・移行可能

## 🛠️ 新しいサイトを監視対象に追加する方法
各ポータルサイトのリポジトリで、ビルド時に以下の形式の `status.json` を公開ルートに出力するように設定し、ダッシュボードから URL を登録してください：

```json
{
  "site_id": "example-portal",
  "site_name": "サイト名",
  "site_url": "https://...",
  "status": "operational",
  "last_updated": "2026/09/12 04:10:00",
  "total_items": 100,
  "recent_new_count": 2,
  "recent_items": [
    { "item_id": "item-001", "title": "タイトル..." }
  ]
}
```
