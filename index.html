📖 新しいサイトの追加・AIへの指示手順（コピペ用）
開く ▼

別サイト（DMMや別ジャンルなど）をAIで作成している場合は、以下の**「AIへの指示プロンプト」**をそのまま別サイトのAIに貼り付けるだけで、自動的にこのダッシュボードと連携できる status.json が出力されるようになります。

1. 別サイトのAIに送る指示文（クリックでコピー）:
サイトのビルドスクリプト（build.js等）を修正して、ビルド完了時に公開ディレクトリの直下（ルート）へ以下の形式の `status.json` を出力するようにしてください。 【status.json 出力仕様】 - 出力先: 公開フォルダ直下（例: output/site/status.json） - 出力内容: { "site_id": "サイトの一意なID", "site_name": "サイトの正式タイトル", "site_url": "サイトの公開URL", "status": "operational", "last_updated": "2026/09/13 13:00:00 (日本時間秒まで)", "total_items": 総記事数・作品数, "recent_new_count": 直近で新規作成された記事数, "recent_updated_count": 既存更新された記事数, "recent_items": [ { "item_id": "作品ID", "title": "作品タイトル", "price": "販売価格", "rating": "4.5", "category": "カテゴリ名", "action": "new または updated" } ] }
2. status.json が公開されたら、このダッシュボードに登録:
  1. 画面右上の 「+ サイト追加」 を押します。
  2. 「公開サイトURL」を貼り付けると、「status.json URL」も自動補完されます。
  3. サイト名を入力して「保存」を押すだけで監視が始まります。
